# Project showcase provenance

The final showcase images are editorial compositions built from repository-owned project evidence. Each `source-captures/` directory preserves the real input used to produce the 1440 × 1020 source PNG and optimized WebP derivative in `showcase/`.

| Project | Real evidence used | Showcase treatment |
| --- | --- | --- |
| TomatoVision | Matching source scene, YOLOv11 baseline output, three-model WBF output, and the recorded evaluation summary | Research plates, matched-scene comparison, and exact result hierarchy |
| Padel Vision | Frames extracted from the source broadcast, player detection, ball tracking, court projection, and final annotated output | Broadcast pipeline and five-stage evidence player |
| ObjectTwin | Existing source workspace, generation progress, and browser 3D inspection states | Source-to-generation studio with 3D inspection as the dominant surface |
| Porsche 3D | Existing project recording and model, camera, material, and detail states | Controlled cinematic sequence without replacing the original project media |

## External references

No third-party source code, media, models, branding, or binaries were copied into this repository.

- `OnurErtugral/react-image-comparison-slider` — MIT — interaction reference only; the shipped comparison is a native range input and CSS clip.
- `Simo-03/football-player-detection` — MIT — sports-computer-vision pipeline presentation reference only.
- `AlfredoChavez/Splatz` — MIT — 3D inspection emphasis reference only.
- `nesdesignco/FormDrive` — MIT application source — controlled camera/state reference only. Its separately licensed vehicle assets were not used.
- `brunosimon/folio-2025` — MIT — camera choreography reference only; no code, identity, or media copied.

The temporary donor checkouts lived outside the production tree under `/tmp` and are not part of the application or build.
