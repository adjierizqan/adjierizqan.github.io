# TomatoVision — B Final implementation

The approved B Final (`../b-final/`, Stitch desktop `b47cd61f7f5c4ee18bdfb8aab317a140`, mobile
`1fc4ddf405f742be8bada941b0c15d38`) is implemented in the existing workspace project view. The shell, routing,
the Ask backend and the other project pages are unchanged. There is one shell fix, in its own commit (see below).

## Where it lives

- `components/project-story/ProjectStory.tsx` + `project-story.css`: shared primitives (ProjectHero, EvidenceChip,
  MetricProgression, DetectionComparison, EditorialSection, Figure/FigureCaption, ResearchTable, MethodDiagram,
  ArtifactLinks). Only TomatoVision uses them for now.
- `components/tomatovision/TomatoVisionStory.tsx` + `tomatovision.css`: the page composition, the dense-scene viewer,
  the accuracy/speed scatter, the annotation maps and the Ask block.
- `data/tomatovision.ts`: the verified numbers. `data/tomatovision-annotation-maps.json` holds the annotation geometry
  for four source images, generated by `make_annotation_maps.py` from the dataset's VOC files.
  `data/content-integrity.test.ts` locks both.
- Layout follows the width of the story column (container queries), not the viewport, so at 820 px next to the
  sidebar the page uses the narrow composition.

## Deviations from the approved screenshots, and why

1. **No Known-You Seed Co. field photographs.** No reuse permission was found (the research repo has only an
   AGPL-3.0 code licence; the dataset archive has no licence file). 01 and 06 show annotation-box maps drawn from the
   source label files instead, with the same composition and captions (625 / 12 green / 12 red / 10 orange). The second
   figure in 01 is the raw Combine 4 output for the 10-orange scene (`0005_110sp_1004_L3`).
   The detection outputs themselves still show Known-You scenes underneath; the brief lists them as preferred assets.
2. **Status** reads "Master’s thesis research · 2026" (owner decision), not "manuscript in preparation".
3. **No "Code ↗" link.** `github.com/adjierizqan/tomato-ripeness-yolov11` is private (`gh repo view`: PRIVATE; public
   request: 404). The evidence row says "Code — private research repository".
4. **Evidence rows have no arrows.** Only the private repo had a destination. The source chips scroll to the matching
   evidence row, and a sixth row ("Annotation files") gives `[Annotation files]` a target.
5. **FPS shows three decimals** (18.089 / 18.951 / 11.245), the source values. Two-decimal rounding of 11.245 is
   ambiguous in floating point.
6. **The scatter** puts its labels beside the points and adds a small single/ensemble key. On the narrow layout the axis
   titles become "ms per image" plus "y: mAP@0.5" in the key.
7. **The Ask block** has a visible send button at every width, needed for touch and keyboard users.

## Shell fix (separate commit)

At ≤760 px the drawer (`z-index: 3`) sat under its own scrim (`z-index: 19`). Tapping any project or nav item in the
mobile menu hit the scrim and only closed the menu. The drawer now uses `--aw-z-drawer`. Its shadow also showed at the
left edge while the drawer was closed; it now shows only when the drawer is open.
